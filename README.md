# 引力拓扑 (Gravity Topology)

基于空间计量与 A2A 机制的社区暗网发掘系统

## 项目简介

告别黑盒推荐，用空间计量算出来的"知音"。

本系统通过分析知乎圈子的用户互动数据，发现那些在特征空间上高度相似但现实中没有交互的"隐藏同好对"，并通过 A2A (Agent-to-Agent) 对话生成引力探测报告。

## 系统架构

```
┌─────────────────────────────────────────────────────────────┐
│                    引力拓扑系统                                │
├─────────────────────────────────────────────────────────────┤
│  Step 1: 数据采集层                                           │
│    ├─ 知乎圈子数据（用户互动、发帖、评论）                        │
│    └─ 构建面板数据 Panel Data                                  │
├─────────────────────────────────────────────────────────────┤
│  Step 2: 引力测算层                                           │
│    ├─ TF-IDF 文本向量化                                       │
│    ├─ Cosine Similarity 相似度计算                            │
│    ├─ 行为互动得分叠加                                         │
│    └─ 输出：高潜同好对列表                                      │
├─────────────────────────────────────────────────────────────┤
│  Step 3: A2A 互动层                                           │
│    ├─ 用户人设实例化（基于历史内容）                             │
│    ├─ Agent 对话生成                                           │
│    └─ 引力探测报告 → 私信真实用户                                │
└─────────────────────────────────────────────────────────────┘
```

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 运行演示

```bash
# 演示模式（使用模拟数据）
python main.py demo

# 测试 API 连接
python main.py test

# 采集数据并分析
python main.py collect

# 使用已有数据分析
python main.py analyze
```

## 核心功能

### 数据采集
- 自动采集知乎圈子的帖子和评论数据
- 构建用户互动关系矩阵
- 支持增量采集和数据持久化

### 引力计算
- 基于 TF-IDF + Cosine Similarity 的文本相似度
- 叠加行为互动得分（评论、点赞）
- 发现"隐藏的高潜同好对"

### A2A 对话
- 基于用户历史内容生成 Agent 人设
- 模拟两个 Agent 之间的观点交流
- 生成引力探测报告

| 文件 | 说明 |

| `a2a_dialogue.py` | A2A 对话生成模块 |
| `main.py` | 主程序入口 |

## 配置说明

通过环境变量配置知乎凭证，不要把密钥写进源码：

```powershell
$env:ZHIHU_APP_KEY="your_app_key"
$env:ZHIHU_APP_SECRET="your_app_secret"
$env:OPENAI_API_KEY="your_openai_api_key"
$env:OPENAI_MODEL="gpt-5.5"
```

## API 限流

- 全局限流：10 QPS
- 发布想法：每小时最多 5 条
- 创建评论：每小时每个想法下最多 20 条
